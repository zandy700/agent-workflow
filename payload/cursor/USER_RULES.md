# Agent workflow
- Solve the requested task with the smallest complete change. Preserve user edits, interfaces, validation, error handling, and security. Use existing helpers and dependencies; avoid speculative abstractions.
- Give each independent project task its own session. If a new task does not need context from this session, start a new chat for it, even in the same repo. Keep follow-ups and corrections to the current task here. If you cannot create a chat, ask the user to open one with a brief starter prompt before starting the independent task.
- Before editing, identify the affected callers and observable checks, including boundary cases. Read the code and tests they depend on. State consequential assumptions; ask only when missing information blocks safe progress.
- Read relevant files once. Group independent reads and related edits; avoid one model round trip per tiny operation. Re-read only changed or missing sections. Use a short deterministic script for mechanical changes, with checks that replacements match.
- Keep tool output focused. Save long logs and inspect failures plus the summary. Never hide failing lines. Do not dump whole folders, repeat code in chat, or reread unchanged files to reassure yourself.
- Run checks appropriate to the change; fix failures. Broaden testing only for an unresolved risk or required gate. Report observed results and anything untested. Never claim a test passed without running it. Finish with the outcome, checks and remaining limits.
- Do not read secrets or upload private files for search. Prefer local exact lookup; use installed search tools when required. After a service fails, report once and use available local reads instead of retrying unchanged conditions.
- Preserve existing project instructions. When project documentation is missing, consult the reference's "Project instructions" section. Never create project files in the home directory or modify third-party tool clones.
- Graphify and ICM are on demand. Use an existing graph for unfamiliar relationships; skip graph setup for a small, directly readable task. For repeated exploration or an explicit request, consult "Graphify" or "ICM" in the reference. One repo = one graph and vault namespace; never merge without permission.
- Vault: `~/Obsidian Sync/ObsidianVault`. Recall only relevant project notes when context is missing. Chats sync automatically; never hand-copy or load whole transcripts. Before a reset, write a 5-15 line status note using "Handoff note" in the reference. A note alone does not shrink this chat.
- Read only the relevant section of `~/Scripts/agent-workflow-reference.md` for project docs, documents, handoffs, ADRs, model/delegation choices, ICM, or Graphify. Do not load the reference at startup. Maps need approval; harvest only on request. Propose a checkpoint when finished; commit only on yes, push only when asked.
